# Browser-Tests für index.html

Проверяют приложение в настоящем Chromium (Playwright) на вымышленных данных: команда U19, сезон 2026/27, часы стоят на Sa 07.11.2026 10:00 (Берлин), вход как Admin, без Firebase. Все имена в тестах вымышленные; реальные данные, коды, ссылки и токены сюда не попадают (репозиторий публичный).

## Запуск
```
cd tools/tests
npm install && npx playwright install chromium   # один раз
bash run.sh                  # все тесты против ../../index.html
bash run.sh /путь/к/файлу.html
SHOTS=/tmp/shots bash run.sh # плюс скриншоты (папка должна существовать)
node t_psh110.js             # один тест
```
`run.sh` сначала проверяет синтаксис (`chk.js`: все `<script>` разбираются, скобки CSS сходятся), потом запускает `t_*.js`; код выхода 0 — всё зелёное.

## Правило
Новая функция — новый `t_<что><версия>.js` здесь же; перед каждой выкладкой `bash run.sh` зелёный. Если тест устарел из-за задуманного изменения — поправить проверку и написать в коммите, почему.
